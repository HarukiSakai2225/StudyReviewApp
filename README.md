## 工夫したやり取り
最初の指示では、使ってほしい技術を指定し、また装飾や文章を最小限にするよう指示しました。
これにより、必要最小限の実装でバグの発生を抑えています。

## 詰まったところとどう乗り越えたか
意欲向上のために、これまでに取り組んだ教材を一覧できる機能を追加しました。
しかし、取り組む教材によってページ数が違うため、実績一覧で見ると
・学習途中なのか、すべてやり終えたのかわからない
・ページ数が相対的に少ない教材が見にくい
という問題がありました。
対策として、パーセントで相対的に表示し、進捗状況がすぐにわかるようになりました。
